# 摩托产业链韧性图谱

把 350 余家整车、零部件与生产性服务主体组织成**可计算**的供应韧性图谱：
主体先归并去重，再按车型版本把零部件、供应商、认证、产能承诺、共享设备、
交期与候选替代连接起来。整车厂收到关键供应商停产通知时，可在秒级得到
燃油、智能电动、越野三类车型分别有多少订单受影响、用哪些备选组合接住、
还剩多少缺口；园区可据此核验真实本地配套率、识别单点依赖，并对比扶持
措施前后的交付能力。

## 场景叙事（样本数据）

`2026-09-28`（周一）整车厂"陵江机车"收到关键齿轮企业"精铸齿轮"停产通知。
精铸同时是燃油/越野车型**齿轮组**与电动车型**减速齿轮**的主供，候选包括：

- 华锐齿轮：本地量产备选，与精铸共享同一条渗碳淬火炉；
- 恒力齿轮：本地试制，10-12 起三周爬坡转量产；
- 安迅齿轮：本地试制，园区认证加速辅导后可用；
- 外源齿轮：外地量产备选，交期四周，园区给予紧急采购补贴。

样本同时埋设：共享热处理炉 10-12 检修五天、某电控备选质量暂停、某外地
轮胎备选报价失效，以及功率芯片晶圆（外地独源）、稀土磁钢（本地独源）
两个结构性单点。

```bash
python scripts/generate_sample.py   # 生成 fixtures/sample_graph.json（354 家主体）
python scripts/demo.py              # 打印断供问答、替代组合与园区分析
```

## 计算口径

### 1. 主体归并（`registry.py`）

同一社会信用代码直接归并；无代码时按归一化名称（剥离地区前缀与
"有限公司/股份/集团"等后缀）与别名归并。所有边只持有规范主体 id。
样本中 379 条原始登记收敛为 354 家主体，"精铸齿轮总厂""（重庆）精铸
齿轮股份有限公司"等写法都指向同一企业。

### 2. 时效可用性（`availability.py`）

快照按评估日（周）计算每条"零件×供应商×车型版本"链接是否可承接订单。
五类事件各按生效窗口改变状态：

| 事件 | 效果 |
| --- | --- |
| 试制转量产 `ramp` | trial 认证转 mass；爬坡曲线按周限制产能 |
| 质量暂停 `quality_hold` | 窗口内认证/链接产能为 0，`[from,to)` 到日恢复 |
| 价格失效 `price_expiry` | 物理产能保留，但旧报价下不可承接（商务阻断） |
| 设备检修 `maintenance` | 按本周停机天数比例折减共享该设备的链接产能；全周停机才阻断 |
| 断供 `supply_stop` | 供应商（可限定零件）窗口内产能为 0 |

可承接还需同时满足：量产认证（或在效的认证加速）、承诺已在线确认、
报价有效。

### 2.1 在线确认（`actions.py`）

零部件企业通过 `confirm_commitment` 在线确认产能承诺；`confirmed=False`
的草案不会进入任何模拟。确认动作带身份校验（只能确认本企业承诺），
确认后整车企业的下一次断供模拟立即把该备选产能纳入计算，形成
"供应商确认 → 整车模拟 → 园区观察"的闭环。

### 3. 断供冲击与替代组合（`impact.py`）

- 订单按交付周、车型版本汇总；
- 每个"零件×供应商"的承诺周产能是跨车型**共享产能池**，不重复计数；
- 危机分配遵循"备选先保既有客户，再用剩余产能救急"，避免备选把产能
  从原有车型抢走造成虚假转移；
- 紧急切换受交期约束（当周已启动的爬坡/认证加速视同当周就绪）；
- 同时计算"无断供基线"与"断供情景"，报告每个零件/车型满足
  **转移量 = 净替代量 + 增量缺口**的替代组合、一次性切换成本与
  相对主供报价的差价；
- 结果按燃油/电动/越野汇总受影响订单笔数与台数，并给出逐周恢复曲线。

### 4. 园区分析（`park.py`）

- **单点依赖**：某零件对某车型版本当前只有一条可用认证供应链接；
  依赖共享设备的会标注隐性单点；
- **真实本地配套率**：公布口径按企业注册地统计，回答不了"某零件此刻
  是否有认证产能"。这里以窗口需求为权重，统计**当前可用认证产能中
  本地供应商的封顶占比**，并列出零认证产能零件；
- **扶持前后对比**：扩产补贴、认证加速、设备备份、单位补贴四类措施
  在同一断供情景下对比受影响台数与残余缺口。

### 5. 商业数据边界（`views.py`）

- 整车企业：只看本企业车型的订单；报价、产能、切换成本等仅对主供与
  已登记候选替代所在的**实际合作链条**开放；竞争整车厂看不到任何订单；
- 零部件企业：只看本企业链接与所供零件需求；
- 质量认证人员：全部认证与暂停状态可见，不见任何报价/产能；
- 园区：结构、认证有无、聚合产能、配套率、单点与扶持对比可见，
  单笔报价、逐笔订单与成本字段一律屏蔽。

```

  domain.py               领域资料读取与校验
  resilience/
    registry.py           主体归并（多名称 → 规范主体）
    graph.py              图谱结构、引用完整性校验、BOM 展开

    availability.py       事件驱动的时效快照与认证产能
    impact.py             断供冲击、产能池分配、替代组合

    views.py              四类角色的权限视图
scripts/
  generate_sample.py      确定性样本生成器（350+ 主体，固定随机种子）
  demo.py                 断供通知端到端演示
fixtures/
  domain.json             领域资料示例
  sample_graph.json       354 家主体的完整样本（由生成器产出）
tests/                    46 个测试（归并/时效/模拟/确认/权限/园区/样本集成）
```
