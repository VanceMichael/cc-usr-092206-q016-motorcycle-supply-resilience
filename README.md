# 摩托产业链韧性图谱

构建高端摩托整车与零部件企业的供应依赖和替代能力。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括整车企业、零部件企业、园区产业服务部门、质量认证人员。

资料所依据的领域事实如下：

- 当地形成燃油、智能电动和越野车型矩阵
- 产业链企业数量多且本地配套比例较高
- 发展计划强调产业链韧性和创新能力

## 韧性图谱

`contracts/graph.schema.json` 规定图谱结构，`fixtures/graph.json` 是由
`fixtures/build_graph.py` 确定性生成的合成示例（355 家主体、6 个车型
版本、167 条供应边，不含真实企业信息）。图谱按
「整车企业 → 车型版本 → 零件 → 供应边」组织，供应边携带认证、产能
承诺、共享设备、交期、价格与候选替代。

### 模块

- `src/names.py` — 企业名称规范化与主体归并：同一企业的全称、简称、
  旧称归并为一个主体（`same_as` 显式声明 + 名称规范化等价）。
- `src/model.py` — 图谱数据模型与加载校验（引用完整性、枚举、日期）。
- `src/graph.py` — 可用性计算与查询：
  - 试制转量产、质量暂停、价格失效、设备检修、断供五类事件按生效
    时间改变供应边状态；量产状态 + 认证生效 + 在线确认才计入产能；
  - `impact_of_supply_stop`：企业停产时按燃油 / 电动 / 越野汇总受
    影响订单，定位受阻零件并列出候选替代；
  - `single_point_parts`：识别只剩一家可用供应商的单点依赖；
  - `certified_local_ratio`：按「此刻是否有本地认证产能」核验真实
    本地配套率，与园区公布值对照；
  - `delivery_capability` / `measure_effect`：观察扶持措施前后的
    交付能力变化；
  - `confirm_supply`：零部件企业在线确认产能承诺；
  - `simulate`：整车企业模拟订单变化与替代组合。
- `src/access.py` — 商业数据（价格、承诺数量）只向实际合作链条开
  放；园区看结构与状态，认证人员只看认证信息。

### 示例场景（图谱内置）

关键齿轮企业 9-20 断供：F250 受影响 700 单、X450 受影响 500 单、
电动车型不受影响；F250 有月产能 500 的登记候选可切换，X450 的候选
要到 10-15 才试制转量产（即扶持措施 M1 的生效日）。

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。

```bash
python fixtures/build_graph.py   # 重新生成示例图谱（确定性）
python -m unittest discover -s tests
```
